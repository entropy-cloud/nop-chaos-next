# Manual Test Issues - 2026-08-10

## 1. 点击 CRUD checkbox（行/表头）触发列表重新请求，界面闪烁

- **所属模块**: flux CRUD（`@nop-chaos/flux` `useCrudLoadAction`）— 原型页 `prototypes/flux-demo/pages/system/products.json`
- **问题描述**: 在 flux-prototype 的产品管理页，点击任意行 checkbox 或表头全选 checkbox 后，列表会重新发起 `GET /api/mock/products?page=1&perPage=10`（实测每次点击 delta +1 请求），表格区域出现 loading 闪烁。
- **预期行为**: selection 是纯客户端状态，点击 checkbox 只应切换选中态，**不应**重新请求数据。
- **发现方式**: 人工测试（用户发现界面闪烁）
- **状态**: 已修复（上游 + 宿主同步，2026-08-10）

### 根因

两层：

1. **上游实现缺陷**（`nop-chaos-flux/packages/flux-renderers-data/src/crud-renderer-load.ts`）：`useCrudLoadAction` 的 imperative load effect 依赖数组**包含 `selection`**。点击 checkbox → scope 的 `selectionStatePath` 更新 → `useScopeSelector` 返回新引用 → effect 重跑 → `loadReaction.dispatch()` 重新派发 → 重新请求。
2. **上游测试假阳性（双重复合）**：
   - 测试 schema 用 `selectable: true` —— **该字段不是 CRUD schema 有效字段**（真实字段是 `selection?: CrudSelectionConfig`），checkbox 列从未渲染，`querySelectorAll` 匹配 0 个元素；
   - 即使换成 `selection: {}`（渲染了 checkbox），jsdom 里 `fireEvent.click` 也无法切换 Base UI checkbox：Base UI 的 onClick 会 `new PointerEvent('click')` 转发到内部隐藏 input，jsdom 对合成事件不模拟原生 checkbox toggle，change 永不触发。
   
   两层叠加导致"点击 checkbox 后断言仍 1 次 load"恒真 —— 缺陷从未被测试拦住。

### 修复

**上游**（`nop-chaos-flux`）：
- `crud-renderer-load.ts`：从 load effect 依赖数组移除 `selection`，新增 `selectionRef` 同步最新值，dispatch 时读 `selectionRef.current`（bindings 仍携带最新 selection，但 selection 变化不再触发重跑）。
- `crud-loadaction-reaction-regression.test.tsx`（测试变有效）：
  - schema 改用 `selection: {}`（真实渲染 checkbox 列）
  - 交互改用 `fireEvent.change(input, { target: { checked: true } })`（直接触发 Base UI 的 onChange，绕开 jsdom 无法模拟的 click→PointerEvent→原生 toggle 链路）
  - 断言 `checkedAfter.length > 0`（点击真的切换了 selection，防假阳性）
  - 断言 load 调用仍为 1（selection 变化不触发 refetch）

**宿主**（`nop-chaos-next`）：`pnpm refresh:flux` 重新打 tgz 并同步；新增防回归 e2e `tests/e2e/crud-selection-no-refetch.spec.ts`（行/表头 checkbox 点击后请求数不变 + 选中态正常切换）。

### 验证

- 上游：`crud-loadaction-reaction-regression` 5/5（有效点击 + 防假阳性断言）；flux-renderers-data 全量 119 文件 / 855 测试通过。
- 宿主：`crud-selection-no-refetch.spec.ts` 1/1；`[data-slot='table-loading-overlay']` 实测点击后不出现；flux 全量 CRUD e2e 16/16；typecheck 28/28。
- 实测：行 checkbox 点击 delta 0 请求、表头 checkbox 点击 delta 0 请求、无 loading overlay。
