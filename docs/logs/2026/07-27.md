# Development Log — 2026-07-27

### 2026-07-27

- **Flux mode E2E 测试调试（nop-entropy-e2e）** — 修复 flux 模式下 7 个核心集成问题，使用户管理 E2E 测试从全部失败推进到 7 passed + 4 failed。

  - **Fix 1: CRUD loadAction signal abort 导致表格空白**
    - 根因：`useCrudLoadAction` 的 per-fire AbortController 在 deps 变化时 abort 旧 signal。`mainHttpClient` 响应 abort 后把无 reason 的 parent abort 误判为 timeout，返回 `{ok:false}` → crud 进入 error 状态。
    - 修复：fetcher 不传 `ctx.signal`（flux 的 `cancelled` flag 已足够处理 cancel 语义）。
    - 关键证据：mock fetcher（同步、不监听 signal）渲染正常；nopRpcRequest（传 signal）不渲染。

  - **Fix 2: 表单 Tabs 组件字段名不兼容**
    - 根因：后端 XPL（`flux-web.xlib:GenLayoutTabs`）生成 `tabs` 字段（AMIS 格式），flux TabsSchema 用 `items`。
    - 修复：通过 `applyPageTransformers` 注册 `flux:tabs-items-body` transformer，运行时统一转换 `items[i].tab` → `items[i].body`。
    - 后端：GenLayoutTabs 外层字段名改为 `items`（XPL 保留字 `body` 不能直接用于子元素名）。

  - **Fix 3: Dict 加载失败（`@selection` 传递问题）**
    - 根因：`nopRpcRequest` 把 `@query:DictProvider__getDict/options{value,label}` 转换为 `/r/DictProvider__getDict` 时丢弃了 selection 部分。REST RPC 的字段投影通过 `?@selection=...` URL 参数传递，`gql:selection` 在 body 中被拒绝。
    - 修复：`nopRpcRequest` regex 增强为 `^@[a-zA-Z]+:([^/?]+)(?:\/([^?]+))?`，提取 selection 并追加为 `?@selection=<encoded>` 查询参数。
    - 关键证据：intercept 响应确认 `options: [{value:"1", label:"普通用户"}, ...]`。

  - **Fix 4: 表单提交数据为空（submitAction 不传 formData）**
    - 根因：`page_simple.xpl` 的 submitAction 用 `data: _n.data`（为 null），未包含表单数据。即使包含，`$fieldName` 是 XPL 模板语法，flux 运行时用 `${fieldName}`。
    - 修复：改为 `data: {data: genScope.formData}`，且 `formData` 模板改为 `${fieldName}` 语法。
    - 关键证据：修复前 backend log 显示 `NopAuthUser__save参数[data]不允许为空`；修复后 `errorCode=null` 且对话框关闭。

  - **Fix 5: onSubmitSuccess 动作顺序导致刷新失效**
    - 根因：`closeSurface` 先于 `refreshTable` 执行，表面关闭后 action 上下文被销毁，`then` 链中断。
    - 修复：先 `refreshTable` 后 `closeSurface`。

  - **Fix 6: E2E 适配器（FluxAdapter）修复**
    - 提交按钮：`getByRole('button', { name: /确定/ })` 改为 `locator('button').filter({ hasText: /确定/ })`（flux button 组件 accessible name 可能与预期不同）。
    - combobox 交互：使用 flux canonical pattern（focus input → ArrowDown → click first option），因 dict 数据加载后才生效。

  - **Fix 7: Quarkus live-reload 全局禁用**
    - 所有 16 个 `*-app` 模块 + codegen 模板中配置 `quarkus.live-reload.enabled: false` + `quarkus.dev.watch.enabled: false`。
