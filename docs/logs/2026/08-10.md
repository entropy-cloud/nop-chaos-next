### 2026-08-10 续（分页器三路径排查 + 序号列 + checkbox 列）

用户追问"缺省应该有分页器"——验证后**确认 flux 缺省行为正确**，并定位了此前"翻页后序号不更新"的根因是**配置路径错误**：

- **关键发现：flux CRUD 分页有三套并存机制**（详见分析文档 §6a）：
  1. **坏路径**：`footerToolbar: [{ "type": "pagination" }]`（crud.md 文档示例）—— 独立 `pagination` renderer 是自包含组件，点击只更新自身 DOM，**不触发 loadAction 重载**。此前"翻页后序号停在 1"即此根因。
  2. **缺省正确路径**（推荐）：不写任何分页配置 → table 内建 `TablePaginationBar` 自动出现（完整页码 + 省略号 + pageSize 选择器 + "1-10 of 15" 统计），`flex justify-between` 左中右布局，翻页走 CRUD `handlePageChange` → scope 分页状态 → loadAction 重载。
  3. **显式自定义路径**：`toolbarLayout: { footer: [{ type: "statistics", align: "left" }, { type: "pagination", align: "right" }] }` —— `CrudToolbarBlocks` 左右拆分同一行，`pagination` block 走 `handleToolbarPageChange`（联动正确），中文"共 X 条"，但分页是简化版（`‹ 第 X / Y 页 ›` 无页码列表）；配置后内建栏被抑制。
- **上游测试确认功能已实现**（用户要求先查 flux 测试）：
  - `table-index-column.test.tsx`：序号列跨页 offset = `(currentPage-1)*pageSize`，第 2 页从 11 开始 ✅
  - `crud-loadaction-reaction-regression.test.tsx`：翻页触发 loadAction 重派发（calls >= 2）、paginationStatePath 变化恰好一次重载 ✅
  - `crud-auto-pagination.test.tsx`：`__autoPagination`（page/perPage）注入 ✅
- **序号列**：`{ "type": "index", "name": "index", "label": "序号", "width": 50 }`（flux-guide 文档列类型），原生跨页累计行号 + `text-center` 居中，**无需改源码**。
- **checkbox 列**：`selection: {}` 加回；居中用 CSS（`[data-slot='table-select-column'/'table-select-cell']` text-align center + checkbox `margin-inline: auto`），实测 offset = 0px。AMIS 侧同步加 `checkable: true` + `{ "type": "index" }` 序号列。
- **CSS 修复**：`[data-slot='crud-footer']` 移除 `display: flex; justify-content: flex-end`（这是旧方案为独立 pagination 加的，会破坏 toolbarLayout 全宽布局）；改为仅 `margin-top: -4px`。
