### 2026-08-08 (flux 模式 findPage 查询归一化：嵌套 filter_* 键转换)

用户反馈访问 nop-app-erp 后端报错：`类型为[class io.nop.api.core.beans.query.QueryBean]的对象不支持属性:filter_status__eq`，并确认是 flux 模式的问题。

- **根因**：flux 模式 CRUD 的 queryForm 原始字段名（`filter_<field>__<op>`，由后端 `flux-web.xlib` 生成）经 `component:querySubmit` 整体写入 CRUD `query` 状态，`loadAction` 的 `includeScope:'*'` 又把整个 scope 投影作为请求 data，导致 `filter_status__eq` 嵌套在 `data.query` 内部到达 host。host 的 `argQuery` 只对 data 顶层键调用 `toFilter`，嵌套键原样透传。
- **后端为何不兜底**：`GraphQLArgsHelper.normalizeQueryArgs` 只处理顶层 `filter_*` 参数，不递归进 `query` 对象内部；且 `isNormalized()` 在请求只含 `query` 键时短路跳过。`filter_status__eq` 一旦进入 `query` 内部即按原样反射绑定 QueryBean → `ERR_REFLECT_UNKNOWN_BEAN_PROP`。AMIS 模式正常是因为 `filter_*` 在 data 顶层、`toFilter` 能扫到。
- **修复**（保证到达后端的格式 AMIS/flux 一致）：
  - `apps/main/src/services/nopRpcResolver.ts`（flux 路径）：`argQuery` 新增 `normalizeNestedFilters`，把 `data.query` 内部嵌套的 `filter_*` 键转成 TreeBean 合并进 `query.filter` 并删除残留键。
  - `packages/amis-core/src/core/graphqlArgs.ts`（AMIS 路径）：同步同一逻辑（嵌套转换时排除 `options.filter` 避免重复合并）。
- **验证**：`nopRpcResolver.test.ts` 28 tests（+3 新增：嵌套转换与残留键移除、与既有 query.filter 合并、between 解析）27 passed，唯一失败为既有基线（stash 对比确认）；`graphqlArgs.test.ts` 64 tests（+2 新增）全绿；main + amis-core typecheck ✅。src/services 全量 11 失败经 git stash 对比确认为工作区既有状态（authApi 7 + pageApi 3 + nopRpcResolver 1），非本次引入。
- 无文档改动需求（修复不改变包边界/插件系统/路由）。

### 2026-08-08 (Flux 与 AMIS 样式一致性分析报告)

用户反馈 flux 组件样式与 AMIS 组件不一致（表单间隔、控件圆角等），并疑问"CSS variable 应该对 amis 和 flux 都起作用"。完成专项检查并输出分析报告：`docs/analysis/2026-08-08-flux-amis-style-consistency-analysis.md`。

- **结论**：颜色 token 已通过 `amis-theme-bridge.css` 打通共用；但"间距/圆角/尺寸"两套体系未打通，是大量不一致的根因。
- **实测差异**（host 当前值）：
  - 圆角：AMIS 控件主流 radius-2/3（bridge 后 4–8px，cxd 用量 148+49 处）；flux input/button/select 用 `rounded-lg` = `--radius-lg` = 16px → flux 偏大一倍。
  - 表单 item 间距：AMIS `--Form-item-gap` = `--sizes-base-12` = 24px；flux `--space-form-item-gap` = 16px。
  - 控件高度：AMIS 32px（`--Form-input-height`）；flux select/combobox 32px、按钮 h-9 = 36px。
  - label 字号 13px 硬编码（flux）vs AMIS 14px 级；`--nop-field-error` 未定义导致必填/错误色永远走硬编码 `#b53b2c`。
- **根因**：① `amis-theme-bridge.css` 只映射 colors/radius/shadows，未映射 `--sizes-*`/`--gap-*`/`--Form-*`；② radius 映射语义与 flux 使用点（rounded-lg/md）错位；③ host 手抄的 `flux-spacing.css` 与上游 `default-spacing.css` diff 出 9 处漂移（fieldset/legend/tabs-content/label-align-right 等）；④ flux 控件形状由 Tailwind 类决定，改变量不会传导。
- **报告给出 5 个修复方向**（补 bridge 映射 / 对齐 radius 语义（上游 ui 包收敛 rounded 等级）/ 删除 host 副本 / 修硬编码 / 视觉回归），未实施，等待用户确认方向。
- 仅产出分析文档，无代码改动。
