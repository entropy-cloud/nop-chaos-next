# 设计模式 Cookbook

常见业务场景的标准解法。每个模式是一个自包含的完整 JSON，可直接参考。

| # | 模式 | 场景 |
|---|------|------|
| 1 | `crud.md` | 标准 CRUD + 搜索 + 新增/编辑/删除 |
| 2 | `combo.md` | 动态增删表单项（订单明细） |
| 3 | `chaining.md` | API 链式调用 / 并行请求 / 循环批量 |
| 4 | `conditional.md` | 显隐 + 选项联动 + autoFill |
| 5 | `custom.md` | 自定义组件 / 自定义表单项 / 自定义动作 |
